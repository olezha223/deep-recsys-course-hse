**Эта статья (ICML 2024) от Meta AI** — одна из самых значимых работ в RecSys за последние годы. Она радикально меняет парадигму промышленных рекомендательных систем.

### Что они предложили?

**Ключевой тезис**: "Actions Speak Louder than Words" — пользовательские **действия** (лайки, просмотры, скроллы и т.д.) гораздо важнее, чем слова/текстовые описания. Авторы предлагают **Generative Recommenders (GRs)** — полностью генеративную парадигму вместо традиционных DLRM (Deep Learning Recommendation Models).

#### Основные инновации:

1. **Reformulation задач как sequential transduction (generative modeling)**:
   - Всё сводится к одной последовательности токенов: история взаимодействий пользователя (items + actions).
   - **Ranking** → предсказание следующего *action* (target-aware, interleaving item + action).
   - **Retrieval** → предсказание следующего *item*.
   - Heterogeneous features (тысячи sparse + dense) унифицируются в одну длинную последовательность (до 8192+ токенов). Числовые фичи частично "выучиваются" моделью при достаточной длине последовательности.

2. **Новая архитектура — HSTU (Hierarchical Sequential Transduction Unit)**:
   - Специально под высококардинальные, нестационарные (streaming) данные рекомендаций.
   - **Pointwise aggregated attention** (вместо softmax) — лучше захватывает интенсивность предпочтений.
   - Упрощённый дизайн (меньше линейных слоёв, агрессивный fusion) → сильно меньше памяти активаций.
   - Relative attention bias с позиционной + временной информацией.
   - Иерархическая структура, адаптированная под рекомендации.

3. **Алгоритмические улучшения**:
   - **Stochastic Length (SL)**: искусственно увеличивает sparsity последовательностей без потери качества.
   - **M-FALCON**: micro-batching + KV-caching для эффективного scoring тысяч кандидатов на inference (target-aware cross-attention).

**Результаты**:
- До **+65.8% NDCG** на публичных датасетах vs Transformers.
- **5.3x–15.2x** быстрее FlashAttention-2 на длинных последовательностях.
- В production (миллиарды пользователей): **+12.4%** онлайн-метрик при 285x более сложной модели.
- Модель на **1.5 триллиона параметров**.
- Впервые показали **scaling law** (power-law) для рекомендаций до масштаба GPT-3 / LLaMA-2.

### Насколько SOTA этот подход в 2026 году?

**Очень сильное влияние, один из главных трендов**.

- **2024–2025**: HSTU/GRs быстро стали reference-подходом. Meta открыла код. Появились follow-up'ы (MTGR от Meituan и др.).
- **2026**: Generative Recommenders — mainstream-парадигма в крупных компаниях (Meta, ByteDance, Kuaishou, Alibaba, Tencent и др.). Традиционные DLRM всё ещё используются, но GRs выигрывают там, где есть много последовательных данных.
- HSTU вошёл в бенчмарки (например, MLPerf Inference DLRMv3 использует HSTU-based архитектуру).
- Продолжают развивать: context parallelism, hierarchical variants, интеграция с MLLM и т.д.

Это не "единственный" SOTA, но **фундаментальный сдвиг** — аналогично тому, как Transformers заменили RNN/LSTM в NLP.

### Влияние на индустрию

- **Парадигмальный сдвиг**: От "feature engineering + two-tower/MLP" к "unified long sequence + generative modeling".
- Показал, что рекомендации могут масштабироваться как LLM (scaling laws работают).
- Значительно снизил барьер для создания **foundation models в RecSys**.
- Эффективность: огромный выигрыш в latency/throughput при большей сложности модели.
- В production Meta: deployed на нескольких поверхностях с миллиардами пользователей → double-digit gains.
- Вдохновил множество follow-up работ и открытых реализаций.

### Схема модели (Generative Recommenders + HSTU)

**Общая идея**:

```
User Action History (long sequence)
   ↓ (unified tokens: Item + Action + other categorical)
[Φ0, a0, Φ1, a1, ..., Φn, an]   ← interleaved
   ↓
HSTU Encoder (stack of HSTU layers)
   - Pointwise Projection (Q,K,V,U)
   - Pointwise Aggregated Attention + Relative Bias (pos + time)
   - Gating + Output
   ↓ (causal, target-aware)
Prediction Head
   ↓
Next Action (Ranking) или Next Item (Retrieval)
```

**HSTU Layer (упрощённо)**:

```
Input X
   ↓
f1(X) → Split → Q, K, V, U
   ↓
Attention: Norm( QK^T + rab^{p,t} ) V     ← Pointwise aggregated
   ↓
Norm(·) ⊙ U → f2(·) → Output Y
   (residual connection)
```

Это позволяет эффективно работать с очень длинными последовательностями и огромным vocabulary.

- **TIGER** (Google 2023) — generative retrieval с Semantic IDs (в основном для candidate generation).
- **HSTU/GR** (Meta 2024) — полноценная generative парадигма для **ranking + retrieval**, с trillion-scale моделями и production impact.
