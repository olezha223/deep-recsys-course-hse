**Retrieval with Learned Similarities (RAILS, 2025)** — статья от Microsoft Research + Meta (Bailu Ding & Jiaqi Zhai), принята на WWW 2025.

### Что они предложили

**Главная проблема:** Современные retrieval-модели (особенно SOTA) давно ушли от простого dot-product (MIPS), перейдя к **learned similarities**:
- Multiple embeddings + max
- Generative retrieval (seq2seq / decoder-only генерация item ID)
- Сложные нейронные сети
- Гибриды

Но эффективного способа делать **быстрый top-k** для таких функций почти не было (brute-force слишком медленный, а индексы ломались).

**Решение — Mixture-of-Logits (MoL):**

MoL — это **универсальный аппроксиматор** любой learned similarity функции.

Формула (внешний вид):

$$
\phi(q, x) = \sum_{p=1}^{P} \pi_p(q,x) \langle f_p(q), g_p(x) \rangle
$$

- Каждый query и item представляются **несколькими** низкоранговыми embeddings ($P$ пар).
- $\pi_p(q,x)$ — learned gating weights (мягкий роутер).
- В итоге — взвешенная сумма dot-products.

**Ключевые вклады:**
1. **Теорема**: MoL — universal approximator (может аппроксимировать любую матрицу сходства с произвольным рангом).
2. **Mutual Information Load Balancing Loss** — улучшает обучение gating weights (равномерная нагрузка + sparsity).
3. **Эффективные approximate top-k алгоритмы** с теоретическими гарантиями (tight error bounds):
   - Top-K per embedding
   - Top-K average
   - Combined

Это позволяет получить почти точный top-k **гораздо быстрее** MIPS-подобных методов.

### Насколько это SOTA в 2026 году

**Очень сильная работа**, особенно в retrieval-слое.

- **Качество**: Новые SOTA на sequential recommendation (MovieLens, Amazon Books) и Question Answering (NQ320K).
  - +20–30% по Hit Rate относительно сильных dot-product и generative baselines.
- **Скорость**: Approximate top-k — до **66×** быстрее brute-force при recall > 0.99.
- Хорошо работает как в recommendation (heterogeneous features), так и в NLP (homogeneous token embeddings).

В 2026 году это один из самых перспективных подходов для **следующего поколения vector databases** и retrieval в промышленных RecSys / RAG.

### Влияние на индустрию

- **Практическое**: Показывает путь миграции от классического MIPS/dot-product к expressive learned similarities без огромных потерь в latency.
- **Теоретическое**: Даёт универсальный интерфейс (MoL) для разных learned similarities.
- **Инженерное**: Алгоритмы хорошо ложатся на GPU (высокая arithmetic intensity), легко интегрируются в существующие vector DB (FAISS, etc.).
- Open-source (код + чекпоинты) — уже используется сообществом.

Ожидаемое влияние: в 2026–2027 многие крупные компании (Meta, Microsoft, ByteDance, Alibaba и т.д.) начнут активно экспериментировать/переходить на MoL-подобные similarity в retrieval stage.

### Схема подхода (RAILS + MoL)

```
Query (q)                          Item Corpus (x ∈ X, billions)
   ↓                                   ↓
Query Encoder                    Item Encoder
   ↓                                   ↓
Multiple component-level         Multiple component-level
embeddings f₁(q), ..., f_P(q)    embeddings g₁(x), ..., g_P(x)
   ↓                                   ↓
        ┌──────────────────────────────┐
        │       Mixture-of-Logits      │
        │  ϕ(q,x) = Σ π_p(q,x)·<f_p,g_p> │
        │   (gating weights π learned)  │
        └──────────────────────────────┘
                    ↓
         Approximate Top-K Retrieval
   (TopK per embedding + TopK average + Combined)
                    ↓
             Top-K candidates (high recall, low latency)
                    ↓
          (Optional) Re-ranker / Ranking stage
```

**Внутри MoL (упрощённо):**

```
Query Embeddings          Item Embeddings
[f1(q), f2(q), ..., fP(q)]   [g1(x), g2(x), ..., gP(x)]
          ↓                         ↓
     Learned Gating π_p(q,x)   (can be sparse)
          ↓                         ↓
       Weighted Sum of Dot Products → Similarity Score ϕ(q,x)
```
